This document explains the strict compatibility requirements that plugins must meet to run on Folia. Folia's regionised multithreading architecture is fundamentally incompatible with traditional plugins, requiring explicit developer acknowledgment before plugins can be loaded.

The folia-supported Flag

Folia enforces a mandatory compatibility declaration to prevent loading incompatible plugins. This requirement is implemented through a folia-supported flag in the plugin's metadata.

Rationale

Folia represents a major architectural breakage from Paper's single-threaded model. The vast majority of existing plugins will not function correctly on Folia without modification. To prevent user confusion from cryptic errors caused by incompatible plugins, Folia refuses to load any plugin that has not been explicitly marked as compatible.

Sources: folia-api/paper-patches/features/0003-Require-plugins-to-be-explicitly-marked-as-Folia-sup.patch1-14

Deprecated and Disabled Systems

BukkitScheduler Deprecation

The traditional BukkitScheduler is marked as @Deprecated in Folia. Developers are directed to use the new region-aware schedulers.

Sources: folia-api/paper-patches/features/0002-Region-scheduler-API.patch33-42

Timings Disablement

The legacy Timings system is force-disabled in Folia because it is not compatible with region-threaded profiling. Timings.setTimingsEnabled(boolean) is patched to always set the state to false.

Sources: folia-api/paper-patches/features/0001-Force-disable-timings.patch8-20

Thread Ownership Enforcement

Folia enforces thread safety through ownership checks. If a plugin attempts to access world data (blocks, entities, chunks) from the wrong thread, the server will often throw an IllegalStateException.

Context Verification

The TickThread utility class provides methods to verify if the current thread owns a specific location or entity.

MethodPurpose
isTickThreadFor(Level, BlockPos)Checks if current thread owns the region containing the position
isTickThreadFor(Entity)Checks if current thread owns the region containing the entity
isShutdownThread()Identifies if the thread is the RegionShutdownThread

Thread Context Logic

The server determines ownership by checking the ThreadedRegion associated with the current thread via TickRegionScheduler.getCurrentRegion().

Compatibility Checklist for Developers

Declaring folia-supported: true is a contract that the developer has:

  1. Migrated Schedulers: Replaced BukkitScheduler with RegionScheduler, EntityScheduler, AsyncScheduler, or GlobalRegionScheduler.
  2. Handled Threading: Ensured that all entity/block interactions occur on the correct region thread.
  3. Validated Thread Safety: Used TickThread or Bukkit's ownership APIs to verify context where necessary.
  4. Acknowledged API Changes: Adjusted to the fact that legacy systems like Timings are disabled.
